# 使用指南

适用 `0.3.0`，电脑上的 Edge / Chrome，以及 HTTPS 的学习通、雨课堂主域名和子域名。无需 Node.js，继续使用浏览器中已登录的课程账号。

## 推荐：脚本版

安装一次 [Tampermonkey](https://www.tampermonkey.net/index.php?browser=edge)，打开本仓库 `userscript/course-helper.user.js` 的 **Raw** 页面并确认安装。也可下载 Releases 的 `course-helper.user.js`。刷新课程页，右下角会出现“课程助手”。完整步骤和首次授权说明见 [脚本安装指南](INSTALL_USERSCRIPT.md)。

若浏览器只下载了文件，用 Tampermonkey 管理面板“实用工具 / Utilities”导入。不要把 GitHub HTML 预览页当作脚本地址。脚本版与扩展版只启用一种；API 设置各自保存。

## 继续使用扩展版

1. 下载 `course-helper-v0.3.0.zip`，完整解压到长期保留的目录。
2. Edge 打开 `edge://extensions`，开启开发人员模式，加载直接含 `manifest.json` 的目录。Chrome 对应 `chrome://extensions`。
3. 从旧版升级时覆盖原目录文件，再点击扩展卡片“重新加载”。
4. 刷新课程页，使用右下角面板；工具栏弹窗仍可用。

整仓源码包请选择 `extension/`，不要选源码根目录。安装后保留目录。步骤参考 [Microsoft 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。

## 倍速与连播

打开具体视频章节，选择 `0.5× / 1× / 1.25× / 1.5× / 2× / 3× / 4×`，点击“开始 / 继续”。若浏览器拒绝播放，先在网页播放器点一次播放。需要连续播放时勾选“自动下一节”，默认关闭。

倍速改变实际播放器速度，不伪造进度。平台可能限制速度或暂停视频，完成情况以平台显示为准。目录未适配、有未完成任务或锁定项时，自动下一节停止并提示。

跨域播放器初次识别时，请滚动到视频可见处并等待约 1–2 秒；跨域父目录可能仍需手动切换。收起面板不会暂停，需要停止时点击“暂停”或网页播放器按钮。普通刷新与换课程后需要重新开始。

## 第一次配置 AI

点击面板中的“API 设置”：

| 字段 | 填写方法 |
| --- | --- |
| API 地址 | 服务商的兼容 Chat Completions 基础地址或完整 `/chat/completions` 地址 |
| API Key | 对应服务密钥，默认隐藏，不需要发给作者 |
| 模型名称 | 服务商控制台提供的真实模型 ID |
| 自动填写 | 默认开启；关闭时只显示答案和解析 |
| 自动提交 | 默认开启；关闭后由你检查提交。关闭自动填写时也关闭自动提交 |

扩展保存时仅请求所填 API 域名的权限，拒绝后不保存；脚本管理器也可能要求确认连接目标。使用“保存并测试连接”或脚本设置的“测试连接”核对配置。

题干、选项会发送给 API 服务，连接测试也会发起小请求，可能收费。详情见 [隐私说明](../PRIVACY.md)。

## 自动做题并提交

进入具体题目页并等待加载，点击“AI 做本页题”。面板显示识别、模型分析、填写和提交进度，可展开答案解析。点击“停止”会停止后续处理，已填写或提交内容不会回滚。

只有题目完整识别、模型答全、全部填写成功、快照没有变化且提交入口唯一时才自动提交。存在图片题、未知控件、漏题或页面变化时会停止提交并提示。出现“无法确认提交状态”时先检查平台页面，避免重复点击。

支持可识别的单选、多选、判断和文本题；不同学校页面与富文本编辑器可能需单独适配。AI 答案可能错误，自动提交可能立即被平台记录。需要先检查时，提前关闭“自动提交”。助手不会自动登录、点击“开始考试”、绕过验证码或直接改写平台进度。

## 更新

**脚本版：** 再打开脚本安装链接更新；作者配置更新地址后，也可由管理器检查更新。更新后刷新课程页。

**扩展版：** 停止播放和 AI 任务，下载新 ZIP 覆盖原目录，在扩展页重新加载并刷新课程页。增加权限时按浏览器提示确认。本地加载版不会自动下载 GitHub Release 更新。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 无面板 / 两个面板 | 检查域名、启用状态与脚本首次授权；只启用一种版本，再刷新 |
| 找不到视频 | 进入具体视频章节，等待播放器并滚动到可视区域 |
| 倍速被恢复或停播 | 查看平台提示，使用平台允许的速度 |
| API 401 / 403 / 404 / 429 | 检查密钥、权限、地址或模型、额度与频率 |
| 答案未填写 / 未提交 | 查看模型格式、识别完整性、页面变化和提交入口提示，以及自动提交设置 |
| 无法确认暂停或提交 | 到网页检查实际状态，避免重复提交 |
| 扩展加载缺文件 | 选含 manifest 与生成 `.js` 的目录；整仓源码选 `extension/` |

真实验证范围见 [测试记录](TESTING.md)。反馈提供浏览器版本、平台、页面类型、操作步骤和脱敏截图，不要公开密钥、Cookie、学号或私人课程链接。
