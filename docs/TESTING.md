# 测试记录与实机验收

日期：2026-11-09（Asia/Shanghai）。当前目标版本：0.3.0。

## 证据范围

项目以类型检查、Node 测试、jsdom 脱敏题目 fixtures、模拟媒体和模型 API 验证逻辑。发布前运行 `npm ci`、`npm run verify`、`npm run package:source`；数量和通过状态以当次输出为准。

本次已完成 TypeScript 检查与 140 项自动化测试，全部通过；其中面板、设置和弹窗的 18 项测试也已单独重跑通过。

历史上已观察到学习通个人空间、章节和嵌套文档，雨课堂班级、学习内容和日志；用户截图确认 Edge 安装启用 0.2.0。随后浏览器连接失效，窗口工具因无法可靠识别网址停止操作。这些历史证据不证明 0.3.0 的真实倍速、AI 或提交功能已验收。

## 本地浏览器测试页

运行 `node scripts/preview.mjs`，在浏览器打开 `http://127.0.0.1:4318`。可通过 `COURSE_HELPER_PREVIEW_PORT` 环境变量更换端口。服务器仅绑定本机，关闭终端进程即可停止。

测试页将未经修改的 `userscript.ts` 与共享控制器、API、面板一起构建，在页面提供仅用于测试的 GM 适配器。配置预设为空密钥、`mock` 模型、本机 `/v1` 地址，默认自动填写和提交。网络适配器拒绝其它目标，不连接真实学习账号或远程模型。

页面有单选、多选、简答三题。点击面板“AI 做本页题”应请求本机 `/v1/chat/completions`，选中单选 B、多选 A/C，并填入“测试答案”，最后由页面产生新的“提交成功”提示。页面网络状态显示实际 HTTP 响应。刷新可重置数据。

视频在浏览器中通过 `canvas.captureStream()` 和 `MediaRecorder` 生成约 4 秒短片，再使用本页 Blob URL 循环播放，可观察开始、暂停、`playbackRate` 属性和媒体时间随倍速推进。不支持录制时回退实时流并明确提示；实时流只能验证控件和速率属性。不支持捕获时显示无视频源说明。此测试页不替代下面的真实平台验收。

## 产物检查

- 扩展 ZIP 根目录含 manifest、background/content/popup/options 脚本、页面和图标。
- `userscript/course-helper.user.js` 与 `dist/course-helper.user.js` 的版本应与 manifest 一致。
- 源码包包含两种构建、源码、文档、测试和工作流，排除密钥、依赖、旧 ZIP 和浏览器资料。
- 产物应来自最新源码；CI 检查重新生成后的差异。

## 尚待真实账号验收

当前没有用户 API 密钥与模型配置的真实调用证据，也未完成两平台真实题目的填写、提交闭环。公开发布时应明确限制，不写“全平台端到端通过”。

在自己有权操作、了解提交后果的页面分别验证两种版本，一次只启用一种：

1. 刷新后只出现一个面板，平台识别正确。
2. 开始视频后时间真实增长；切换 1×、1.5×、2×，观察实际速度。高倍速被平台限制时应以平台反馈为准。
3. 面板和网页暂停均有效，迟到播放请求不会恢复。
4. 自然播完视频，检查自动下一节开/关、延时取消与任务阻断。
5. 换课程、刷新、PDF 或无学习内容页面，不应自动接管。
6. 配置真实 API 并测试，检查目标、模型和费用；拒绝域名权限时不应保存或发题目请求。
7. 先关闭自动提交，检查少量题目的提取、答案解析和实际填写是否对应。
8. 开启自动提交后，只有全部识别填写成功时才点击唯一入口；用平台成功反馈确认结果。
9. 图片题、未知控件、模型漏答、页面变化和提交入口不唯一时，不应自动提交。
10. 请求期间停止任务，确认后续填写提交中止；已发生动作不能声称已撤销。

不要通过修改视频时间、伪造结束事件或直接调用进度接口冒充自然播放验收，也不要把“点击了提交”当成“平台成功提交”。记录浏览器版本、页面类型、步骤、实际反馈和脱敏截图，不将 Cookie、密钥、登录链接、学号或姓名存入仓库。
