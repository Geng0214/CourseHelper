# 用油猴脚本安装

脚本版适合希望少操作的用户：安装一次脚本管理器，再安装一个 `.user.js` 文件。以后打开课程网页，右下角就会出现课程助手，不用每次打开浏览器扩展弹窗。

## 首次安装

1. 从 [Tampermonkey 官方网站](https://www.tampermonkey.net/index.php?browser=edge) 前往你的浏览器扩展商店，安装 Tampermonkey。使用官方商店入口，不需要下载第三方安装程序。
2. 在本项目的 Releases 打开 `course-helper.user.js`。如果脚本管理器显示安装页面，检查脚本名称并安装。如果浏览器只下载了文件，打开 Tampermonkey 管理面板，在“实用工具 / Utilities”的文件导入入口选择这个文件。
3. 刷新学习通或雨课堂网页，使用右下角“课程助手”。同一浏览器中请只启用脚本版或扩展版中的一种，避免两个控制器同时操作播放器。

部分 Chromium 浏览器要求为脚本管理器启用“允许用户脚本”或开发者模式。不同版本的入口不同，按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php#Q209) 操作。脚本版省去了每次下载 ZIP、解压、选择文件夹和更新后重新加载扩展的步骤，但不能免除浏览器对脚本管理器的首次授权。

## 使用

进入具体视频章节后，选择倍速并点击开始。倍速改变的是播放器的实际播放速度，不伪造播放进度；平台可能限制可用速度。自动下一节需主动开启。

AI 答题首次使用时打开面板中的 API 设置，填写自己服务的兼容接口地址、密钥和模型。设置保存在脚本管理器的专用存储里，不写入学习平台的网页存储。点击“AI 做本页题”才会把当前识别的题目和选项发送到你配置的 API 服务，可能产生服务费用。请先检查发送目标与服务条款，再保存配置。

题目解析、填答与提交方式以面板的当前设置和状态提示为准；对于无法识别或已经变化的题目，助手会跳过并提示。

默认开启自动填写与自动提交，可以在 API 设置里分别关闭。只有本页题目全部被识别、全部有有效答案并填写成功时，才会尝试点击提交；仍需以平台页面的成功结果为准。取消会停止后续答题和确认步骤，已经发出的提交不能撤销。

## 发布者：提供真正可点击的安装链接

构建命令生成 `userscript/course-helper.user.js`（随源码提交）和 `dist/course-helper.user.js`（Release 附件）。先将文件发布到自己的仓库，再把仓库中脚本的 **Raw 链接**或 Release 附件链接放在 README 的“安装脚本”按钮上。网页链接必须返回 JavaScript 脚本文件，而不是 GitHub 的 HTML 文件预览页。

需要自动更新时，在构建时将环境变量 `COURSE_HELPER_UPDATE_URL` 设置为你自己稳定、公开且以 `.user.js` 结尾的 HTTPS 地址。构建器会写入 `@downloadURL` 与 `@updateURL`。未设置时不会写入虚假的仓库地址，用户可重新打开同一安装链接更新。发布新版本时必须提高 manifest 版本号。

例如仓库确定后，可使用 GitHub 的固定分支 Raw 地址；不要把仓库模板中的用户名占位符当作真实链接。

## 权限与排错

- 脚本仅在 HTTPS 学习通、雨课堂域名及子域名运行；不会在其他普通网站运行。
- `GM_xmlhttpRequest` 用于请求你自己配置的模型 API。由于接口域名由用户指定，脚本声明 `@connect *`；实际请求仍由设置里的完整目标地址决定，脚本管理器可能要求确认该域名连接。
- 不出现面板时，检查脚本已启用、脚本管理器获准在当前网站运行，并刷新网页。
- 无法识别视频时，先滚动到视频可见的位置；跨域播放器第一次登记可能需要数秒。
- API 出错时检查地址、模型和服务余额，使用“测试连接”查看具体提示；不要在公开 Issue 中粘贴密钥。

跨域播放器与题目框架通过脚本管理器的私有消息键协调，不向网页开放消息执行入口。题目与答案仅在操作进行期间临时写入这些键，操作完成、取消或超时后删除；脚本还会定时清理过期键。浏览器突然崩溃时，残留的过期消息会在下次脚本运行时清理。API 配置则保留到用户主动清除或移除脚本。

脚本管理器 API 与元数据格式参考 [Tampermonkey 官方文档](https://www.tampermonkey.net/documentation.php)。实际平台页面验收范围仍以 [测试记录](TESTING.md) 为准。
